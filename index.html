02 / IDEA

Memory in the medium

Input-written edge values replace pixel activity as the stored state. A new query can then traverse the same graph by different paths.

A result that can fail

One trainable writer, five comparison arms, untouched held-out scenes. The code records results rather than inventing a successful benchmark.

THE TASK

Which color is the tiny mark on the queried object?

The synthetic image contains two textured objects and 2×2 red/blue marks. The reader receives only 896-byte W and a query for left or right. The source pixels are inaccessible after writing.

Heads for ordered pair, commutator, symmetric mean, isotropic two-step, and raw W have matched trainable parameters. Ordered and commutator probes consume four transports. Direct-W is an explicit memory-access upper baseline, not compute-matched.
