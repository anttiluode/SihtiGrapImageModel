What the test actually says

Verified algebra. Different learned codes. No universal accuracy improvement.

The conjugate ratio cancels changes in shared intermediate phase values while preserving the difference between source and detector phase. The tests verify that invariant even under deliberately altered intermediate cells.

But direct access to the same single source location is also highly seed-dependent: at two measurements, the equivalent direct-source sample scores 62.74% for seed 41 and 99.95% for seed 97. Seed 41 simply has much less label information in that particular source site. A fixed endpoint reference also varies across scenes, so a relative phase is not a direct-source reading without calibration.

Keeping both uncombined measurements can outperform the ratio because their common phase includes other task-relevant learned features. Cancellation removes those features, whether they are clutter or useful signal.
